# GLOBAL FUSION — Static Website

A responsive, seven-page starter website for an India-based export sourcing and commission-based trade facilitation business.

## Included pages
- `index.html` — Home
- `buyer-connect.html` — International buyer enquiry
- `supplier-connect.html` — Indian supplier enquiry
- `products.html` — Product categories
- `about.html` — About the business
- `contact.html` — General enquiry
- `resources.html` — Buyer and supplier preparation resources

## Before publishing — important customisation
1. Replace `YOUR_BUSINESS_EMAIL@example.com` in:
   - `buyer-connect.html`
   - `supplier-connect.html`
   - `contact.html`
   with the business email address that should receive enquiries.
2. Update the contact details in the footer (`index.html` through `resources.html`) with your verified email and WhatsApp number.
3. Review all business statements. Do not add GST/IEC/registration, certification, export history, buyer relationships, or performance claims unless they are accurate and documented.
4. Add your final logo if you have one. The current GF monogram is a text-based placeholder.
5. Test each form. The forms use a `mailto:` link: they open the visitor's default email application and do not store submissions. This is a no-backend starter solution, not a hosted form inbox.

## Preview locally
Open `index.html` in a browser. Keep the `assets` folder alongside the HTML files.

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a **public** repository named `global-fusion-website` (or another name).
3. Upload all seven HTML files, the `assets` folder, and this README. Keep `index.html` at the repository root.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then save.
7. Wait for GitHub Pages to publish. Your free site URL will be:
   `https://YOUR-GITHUB-USERNAME.github.io/global-fusion-website/`
   Replace `YOUR-GITHUB-USERNAME` with your GitHub username.
8. Open the published URL on desktop and mobile and test all navigation links and forms.

GitHub may take a few minutes to publish after the first setup or a new commit.

## Form behaviour
The forms generate an email draft in the visitor's email app. They do not send automatically, and they will not work as expected until you replace the placeholder email. For a proper hosted form that works without the visitor having an email app configured, connect a form service or backend later.

## Design notes
- Navy and muted-gold visual identity
- Responsive mobile navigation
- No paid theme, external JavaScript library, stock image dependency, or build step
- Original copy and design; inspired by common premium B2B/export website conventions, not a copy of another site's protected branding or text
